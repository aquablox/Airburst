# Create: Airburst

Create: Airburst is a Minecraft 1.21.1 Create addon for NeoForge/Forge-style modpacks.

![Airburst Wand render](docs/airburst_wand_render.png)

## Features

- Adds the Airburst Wand, an Extendo Grip variant powered by Create backtank pressure.
- Uses the Create Extendo Grip model and behavior, with a Wind Charge visual replacing the gripper hand when appropriate.
- `R` performs Airburst, pushing the player in the direction they are facing.
- `G` performs Reverse Airburst, pushing the player in the opposite direction.
- Airburst uses 10 backtank pressure units unless the player is in Creative mode.
- Airburst has a 10 tick cooldown and plays Minecraft's Wind Charge burst sound.
- The wand can mix with Extendo Grips for normal Create reach behavior.

## Crafting

1. Deploy a Breeze Rod onto an Extendo Grip to create an Incomplete Airburst Wand.
2. Deploy a Precision Mechanism onto the Incomplete Airburst Wand to create the Airburst Wand.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Create 6.0.8 or newer

## Controls

- `R`: Airburst
- `G`: Reverse Airburst

Both keybinds can be changed in Minecraft's Options -> Controls screen.
